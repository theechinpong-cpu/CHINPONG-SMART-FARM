พระจอมเกล้าติวเตอร์: แบบฝึกหัดและข้อสอบ Interactive

หน่วยการเรียนรู้: การแปลงทศนิยมและเศษส่วน (รวมทศนิยมซ้ำแบบละเอียด) จำนวน 35 ข้อ

📘 สรุปกระบวนการคิดและสูตรลัด: ทศนิยมและเศษส่วน โดย พระจอมเกล้าติวเตอร์

ระบบจำนวนจริงประกอบด้วยจำนวนตรรกยะ ซึ่งสามารถเขียนให้อยู่ในรูปเศษส่วน $\frac{a}{b}$ เมื่อ $a, b$ เป็นจำนวนเต็ม และ $b \neq 0$ ได้เสมอ ทศนิยมทุกชนิดสามารถแบ่งออกได้เป็น 2 ประเภทหลัก ได้แก่ 1) ทศนิยมรู้จบ (Terminating Decimals) ซึ่งเศษส่วนที่มีตัวส่วนอยู่ในรูปของตัวประกอบเฉพาะ $2^m \times 5^n$ เท่านั้นที่จะหารได้ลงตัวเป็นทศนิยมรู้จบ และ 2) ทศนิยมไม่รู้จบแบบซ้ำ (Repeating Decimals) ซึ่งสามารถแปลงกลับเป็นเศษส่วนของจำนวนเต็มได้เสมอ

⚡ เทคนิคการจำสูตรลัดและกระบวนการคิด (Shortcut Mastery)

1. ทศนิยมรู้จบเป็นเศษส่วน: นับจำนวนตำแหน่งหลังจุดทศนิยมเป็น $k$ ตำแหน่ง ส่วนจะเป็น $10^k$ เสมอ เช่น $0.4 = \frac{4}{10} = \frac{2}{5}$ และ $0.125 = \frac{125}{1000} = \frac{1}{8}$ จากนั้นทอนเป็นเศษส่วนอย่างต่ำด้วย ห.ร.ม.
2. ทศนิยมซ้ำล้วน (Pure Repeating Decimals): ซ้ำกี่ตำแหน่ง ให้ใส่เลข $9$ ในตัวส่วนเท่ากับจำนวนตัวที่ซ้ำ เช่น $$\text{รูปทั่วไป: } 0.\dot{a}_1a_2...\dot{a}_n = \frac{a_1a_2...a_n}{\underbrace{99...9}_{n \text{ ตัว}}}$$ ตัวอย่าง: $0.\dot{7} = \frac{7}{9}$, $0.\dot{3}\dot{6} = \frac{36}{99} = \frac{4}{11}$, $0.\dot{1}8\dot{2} = \frac{182}{999}$
3. ทศนิยมซ้ำระคน (Mixed Repeating Decimals): ใช้สูตรจำขึ้นใจ "(เลขทั้งหมดหลังจุด ลบ เลขที่ไม่ซ้ำ) หารด้วย (เก้าเท่าจำนวนตัวซ้ำ ศูนย์เท่าจำนวนตัวไม่ซ้ำ)" $$\text{สูตรลัด: เศษ} = (\text{เลขทั้งหมดหลังจุด}) - (\text{เลขที่ไม่ซ้ำหลังจุด})$$ $$\text{ส่วน} = \text{ใส่ 9 ตามจำนวนตัวที่ซ้ำ แล้วตามด้วย 0 ตามจำนวนตัวที่ไม่ซ้ำหลังจุด}$$ ตัวอย่าง: $0.1\dot{6} = \frac{16 - 1}{90} = \frac{15}{90} = \frac{1}{6}$ และ $0.23\dot{8} = \frac{238 - 23}{900} = \frac{215}{900} = \frac{43}{180}$
4. จำนวนคละและทศนิยมมากกว่า 1: ให้แยกจำนวนเต็มออกมาก่อนเพื่อลดความซับซ้อนของการคำนวณ เช่น $2.\dot{9} = 2 + 0.\dot{9} = 2 + \frac{9}{9} = 3$ หรือทำเป็นเศษเกินโดยตรงด้วยสูตร $(\text{ตัวเลขทั้งหมด} - \text{ตัวเลขหน้าคาบที่ไม่ซ้ำ}) / \text{ตัวส่วนเดิม}$

กระบวนการคิดเชิงพิสูจน์ (Algebraic Derivation):
หากผู้เรียนลืมสูตรลัด ให้ใช้ตัวแปร $x$ ตั้งเป็นสมการหลัก เช่น ต้องการหาค่าของ $x = 0.2\dot{7}$ ให้นำ $10$ มาคูณเพื่อเลื่อนจุดให้ติดส่วนซ้ำ ได้ $10x = 2.\dot{7}$ เป็นสมการที่ (1) และคูณต่อด้วย $10$ ได้ $100x = 27.\dot{7}$ เป็นสมการที่ (2) เมื่อนำ (2) - (1) ส่วนทศนิยมซ้ำจะหักล้างกันหมดสิ้น เหลือ $90x = 25$ ดังนั้น $x = \frac{25}{90} = \frac{5}{18}$ กระบวนการนี้จะช่วยให้เข้าใจที่มาของสูตรว่าทำไมตัวส่วนจึงเป็นเลข 9 และเลข 0 อย่างถ่องแท้
