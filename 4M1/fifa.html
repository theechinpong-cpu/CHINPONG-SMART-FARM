พระจอมเกล้าติวเตอร์

คลังข้อสอบวิทยาศาสตร์ ม.1: เรื่อง ไฟฟ้า (30 ข้อ - ระดับปานกลาง)
1. ข้อใดกล่าวถึงทิศทางการไหลของกระแสไฟฟ้าในวงจรไฟฟ้าได้อย่างถูกต้อง?
เฉลย: B - กระแสไฟฟ้า (Conventional Current) มีทิศทางการไหลสมมติจากขั้วบวกไปยังขั้วลบของแหล่งกำเนิดไฟฟ้าเสมอ
2. วัสดุในข้อใดจัดเป็น "ฉนวนไฟฟ้า" ทั้งหมด?
เฉลย: C - ยาง พลาสติก และแก้ว เป็นวัสดุที่ไม่อนุญาตให้กระแสไฟฟ้าไหลผ่าน จึงจัดเป็นฉนวนไฟฟ้า
3. การต่อหลอดไฟฟ้าแบบอนุกรมมีลักษณะเด่นอย่างไรเมื่อเทียบกับการต่อแบบขนาน?
เฉลย: C - การต่อแบบอนุกรมมีทางเดินกระแสไฟฟ้าเพียงทางเดียว หากหลอดใดขาด วงจรจะเปิดและดับทั้งหมด
4. บ้านเรือนทั่วไปนิยมต่อเครื่องใช้ไฟฟ้าภายในบ้านแบบใด และเพราะเหตุใด?
เฉลย: B - การต่อแบบขนานช่วยให้เครื่องใช้ไฟฟ้าแต่ละชิ้นทำงานเป็นอิสระต่อกัน แรงดันไฟฟ้าเท่ากัน และหากชิ้นหนึ่งเสีย ชิ้นอื่นยังใช้งานได้
5. เครื่องมือในข้อใดใช้สำหรับวัด "ความต่างศักย์ไฟฟ้า" ในวงจร?
เฉลย: B - โวลต์มิเตอร์ใช้ต่อคร่อมเพื่อวัดความต่างศักย์ไฟฟ้า มีหน่วยเป็นโวลต์ (V)
6. อุปกรณ์ใดทำหน้าที่ตัดวงจรไฟฟ้าอัตโนมัติเมื่อมีกระแสไฟฟ้าไหลผ่านมากเกินไปเพื่อป้องกันไฟไหม้?
เฉลย: B - ฟิวส์จะหลอมละลายและตัดวงจรเมื่อกระแสไฟฟ้าเกิน ส่วนเบรกเกอร์จะทริปตัดไฟอัตโนมัติ
7. การต่อแบตเตอรี่ (ถ่านไฟฉาย) แบบอนุกรมหลายก้อนเรียงกัน จะส่งผลอย่างไรต่อวงจร?
เฉลย: B - การต่อเซลล์ไฟฟ้าแบบอนุกรมจะนำแรงดันมารวมกัน ทำให้พลังงานรวมในวงจรสูงขึ้น
8. อนุภาคใดที่มีการเคลื่อนที่ทำให้เกิดกระแสไฟฟ้าในลวดตัวนำ?
เฉลย: C - กระแสไฟฟ้าในลวดตัวนำเกิดจากการเคลื่อนที่ของอิเล็กตรอนอิสระ (Free electrons) จากขั้วลบไปขั้วบวก
9. หากต้องการวัดกระแสไฟฟ้าที่ไหลผ่านหลอดไฟ จะต้องต่อแอมมิเตอร์ในลักษณะใด?
เฉลย: B - แอมมิเตอร์ต้องต่อแบบอนุกรมเพื่อให้กระแสไฟฟ้าไหลผ่านตัวเครื่องทั้งหมดในการวัด
10. หน่วยวัดทางไฟฟ้าของ "กำลังไฟฟ้า" คือข้อใด?
เฉลย: C - กำลังไฟฟ้ามีหน่วยเป็นวัตต์ (Watt) หรือกิโลวัตต์ (kW)
11. หลอดไฟ LED ขนาด 10 วัตต์ เปิดใช้งานนาน 5 ชั่วโมง จะใช้พลังงานไฟฟ้าไปกี่หน่วย (ยูนิต)?
เฉลย: A - สูตรหน่วยไฟฟ้า = (กิโลวัตต์ × ชั่วโมง) = (10/1000 kW) × 5 ชม. = 0.01 × 5 = 0.05 หน่วย
12. ข้อใดคือสาเหตุหลักที่ทำให้เกิดไฟฟ้าลัดวงจร (Short Circuit)?
เฉลย: B - ไฟฟ้าลัดวงจรเกิดจากกระแสไฟฟ้าเดินทางลัดผ่านจุดที่มีความต้านทานต่ำมาก (สายบวกแตกลัดกับสายลบโดยตรง) ทำให้กระแสพุ่งสูง
13. สายดิน (Ground Wire) ในระบบไฟฟ้าภายในบ้านมีประโยชน์อย่างไร?
เฉลย: C - สายดินทำหน้าที่เป็นทางผ่านให้กระแสไฟที่รั่วจากโครงเครื่องใช้ไฟฟ้าไหลลงดิน ปลอดภัยต่อผู้ใช้งาน
14. สวิตช์ไฟฟ้าทำหน้าที่สำคัญที่สุดในข้อใด?
เฉลย: B - สวิตช์ทำหน้าที่ตัดต่อวงจร หากสับเปิด (Open Circuit) ไฟจะดับ หากสับปิด (Closed Circuit) ไฟจะติด
15. หากนำแท่งแก้วถูด้วยผ้าไหม แท่งแก้วจะมีประจุไฟฟ้าชนิดใด และเพราะเหตุใด?
เฉลย: B - แท่งแก้วเมื่อถูด้วยผ้าไหม อิเล็กตรอนจากแท่งแก้วจะถ่ายโอนไปที่ผ้าไหม ทำให้แท่งแก้วขาดอิเล็กตรอนจึงแสดงประจุบวก
16. ข้อใดคือตัวอย่างของไฟฟ้าสถิตในชีวิตประจำวัน?
เฉลย: C - การหวีผมเกิดการสะสมประจุไฟฟ้าสถิตจากการเสียดสี ทำให้เส้นผมเกิดแรงดึงดูดและชี้ฟู
17. วัตถุสองชิ้นมีประจุไฟฟ้าชนิดเดียวกันเข้าใกล้กัน จะเกิดแรงระหว่างประจุอย่างไร?
เฉลย: B - ประจุเหมือนกันจะผลักกัน และประจุต่างกันจะดึงดูดกัน
18. ถ้าต้องการเพิ่มความสว่างของหลอดไฟในวงจรแบบอนุกรมให้มากขึ้น ควรทำอย่างไรตามหลักการ?
เฉลย: B - การเพิ่มถ่านไฟฉายแบบอนุกรมจะเพิ่มแรงดันไฟฟ้า ทำให้กระแสไหลผ่านหลอดไฟมากขึ้น หลอดจึงสว่างขึ้น
19. อุปกรณ์ไฟฟ้าในบ้านข้อใดเปลี่ยนพลังงานไฟฟ้าเป็น "พลังงานความร้อน" เป็นหลัก?
เฉลย: C - เตารีดและเตาไมโครเวฟเป็นเครื่องใช้ไฟฟ้าที่เปลี่ยนพลังงานไฟฟ้าเป็นพลังงานความร้อนในการใช้งาน
20. ข้อใดกล่าวถูกต้องเกี่ยวกับการใช้เครื่องใช้ไฟฟ้าอย่างประหยัดและปลอดภัย?
เฉลย: B - การถอดปลั๊กและปิดสวิตช์เมื่อไม่ใช้งานช่วยประหยัดไฟ (ลด Standby power) และเพิ่มความปลอดภัย
21. วัสดุใดจัดเป็นตัวนำไฟฟ้าที่ดีที่สุดในบรรดาโลหะทั่วไป?
เฉลย: C - เงินเป็นโลหะที่มีสภาพนำไฟฟ้าสูงที่สุด แต่เนื่องจากมีราคาส่งผลให้นิยมใช้ทองแดงทำสายไฟแทน
22. หากหลอดไฟ 3 หลอดต่อแบบขนาน แล้วหลอดที่ 1 ขาด จะเกิดอะไรขึ้นกับหลอดที่ 2 และ 3?
เฉลย: B - การต่อแบบขนานมีเส้นทางกระแสแยกอิสระ หลอดอื่นจึงไม่ได้รับผลกระทบเมื่อหลอดใดหลอดหนึ่งเสีย
23. ปรากฏการณ์ฟ้าแลบและฟ้าผ่า เกิดจากการถ่ายโอนประจุไฟฟ้าระหว่างสิ่งใด?
เฉลย: A - ฟ้าแลบและฟ้าผ่าเกิดจากการสะสมประจุไฟฟ้าสถิตในก้อนเมฆ แล้วเกิดการคายประจุระหว่างก้อนเมฆด้วยกัน หรือเมฆกับพื้นดิน
24. ข้อใดคือความหมายของ "วงจรเปิด" (Open Circuit)?
เฉลย: C - วงจรเปิดคือวงจรที่ไม่ครบวงจร (มีจุดขาดตอน) กระแสไฟฟ้าจึงไม่สามารถไหลผ่านได้ หลอดไฟจึงไม่ติด
25. อุปกรณ์ไฟฟ้าในข้อใดเปลี่ยนพลังงานไฟฟ้าเป็น "พลังงานกล" (การเคลื่อนที่/หมุน)?
เฉลย: C - มอเตอร์ไฟฟ้าในพัดลมทำหน้าที่เปลี่ยนพลังงานไฟฟ้าเป็นพลังงานกลเพื่อให้ใบพัดหมุน
26. ถ่านไฟฉาย 1.5 โวลต์ จำนวน 3 ก้อน นำมาต่อเรียงกันแบบอนุกรม (ขั้วบวกชนขั้วลบ) จะให้แรงดันไฟฟ้ารวมเท่าใด?
เฉลย: C - การต่อเซลล์ไฟฟ้าแบบอนุกรมนำแรงดันมารวมกัน: 1.5 + 1.5 + 1.5 = 4.5 โวลต์
27. ข้อใดคือประโยชน์ของการใช้ "ฟิวส์" ในเครื่องใช้ไฟฟ้า?
เฉลย: B - ฟิวส์ทำหน้าที่ตัดกระแสไฟเมื่อกระแสเกินพิกัด ป้องกันความเสียหายต่ออุปกรณ์และบ้านเรือน
28. หากพบผู้ประสบภัยถูกกระแสไฟฟ้าดูด สิ่งแรกที่ควรปฏิบัติเพื่อความปลอดภัยคืออะไร?
เฉลย: B - ต้องตัดกระแสไฟหรือใช้วัสดุที่เป็นฉนวน (เช่น ไม้แห้ง) เขี่ยสายไฟออก ห้ามใช้มือเปล่าเด็ดขาดเพราะจะโดนไฟดูดไปด้วย
29. สัญลักษณ์ทางไฟฟ้าในวงจรที่เป็นเส้นตรงยาวสลับกับเส้นสั้นหนา (แบบขีดคู่) หมายถึงอุปกรณ์ใด?
เฉลย: B - สัญลักษณ์เซลล์ไฟฟ้าประกอบด้วยเส้นยาว (ขั้วบวก) และเส้นสั้นหนา (ขั้วลบ)
30. ข้อใดคือพฤติกรรมการใช้ไฟฟ้าที่ **ไม่ถูกต้อง** และเสี่ยงอันตราย?
เฉลย: B - ห้ามใช้อุปกรณ์ใดๆ แหย่เข้าไปในเครื่องใช้ไฟฟ้าที่กำลังเสียบปลั๊กอยู่เด็ดขาด เพราะอาจโดนส่วนที่มีกระแสไฟฟ้าช็อตได้
