2. ชนิดของคำ คำนาม, สรรพนาม, กริยา, วิเศษณ์, บุพบท, สันธาน, อุทาน 15 25.0% ความจำ (Remembering) / การประยุกต์ใช้ (Applying)

4. เสียงและโครงสร้างคำ เสียงในภาษา, คำมูล, คำประสม, คำซ้อน, มาตราตัวสะกด 20 33.3% การวิเคราะห์ (Analyzing) / การประเมินค่า (Evaluating)

ส่วนที่ 1: ระดับภาษา (ข้อ 1 - 15)

1. ข้อความใดใช้ภาษาระดับพิธีการ?
ก. ขอเชิญทุกท่านร่วมส่งกำลังใจให้แก่ทีมชาติไทย ข. ในวโรกาสนี้ ขอพระองค์ทรงพระเจริญยิ่งยืนนาน
ค. วันนี้ที่ประชุมได้ร่วมกันหารือถึงแนวทางแก้ไขปัญหาน้ำท่วม ง. หมอเตือนให้ประชาชนดูแลสุขภาพช่วงอากาศเปลี่ยนแปลง
2. ข้อความใดใช้ภาษาระดับทางการ?
ก. คณะรัฐมนตรีอนุมัติงบประมาณช่วยเหลือผู้ประสบภัยแล้ว ข. ไปเที่ยวทะเลเที่ยวนี้สนุกสุดๆ ไปเลย
ค. ขอเดชะบารมีตระกูลเราจึงรอดพ้นวิกฤตมาได้ ง. กินข้าวเสร็จแล้วค่อยไปทำงานต่อกันนะ
3. "หมอสั่งให้คนไข้กินยาตามเวลาอย่างเคร่งครัด" ประโยคนี้เป็นภาษาระดับใด?
ก. พิธีการ ข. ทางการ
ค. กึ่งทางการ ง. กันเอง
4. ข้อใดเป็นภาษาระดับสนทนา?
ก. รายงานการวิจัยฉบับนี้สรุปผลได้อย่างชัดเจน ข. วันนี้คุณครูติดธุระ จึงขอเลิกชั้นเรียนเร็วขึ้นนิดนึง
ค. กราบเรียนท่านประธานที่เคารพ ง. ประเทศไทยมีแหล่งท่องเที่ยวธรรมชาติที่สวยงาม
5. ข้อความใดใช้ภาษาระดับกันเอง?
ก. แกจะไปงานเลี้ยงเย็นนี้ด้วยหรือเปล่า ข. ขอเชิญรับประทานอาหารร่วมกันครับ
ค. สภาพอากาศวันนี้ค่อนข้างร้อนอบอ้าว ง. โรงเรียนกำหนดเปิดเทอมในสัปดาห์หน้า
6. ภาษาที่ใช้ในหนังสือราชการต้องเป็นภาษาระดับใด?
ก. พิธีการ ข. ทางการ
ค. กึ่งทางการ ง. สนทนา
7. ข้อความใดเป็นการบรรยายในระดับพิธีการ?
ก. ประธานในพิธีจุดธูปเทียนบูชาพระรัตนตรัย ข. ขอเดชะฝ่าพระบาท ปกเกล้าปกกระหม่อม
ค. งานวันนี้จัดได้อย่างราบรื่นและน่าประทับใจ ง. เพื่อนๆ ทุกคนพร้อมกันหรือยัง
8. สถานการณ์ใดควรใช้ภาษาระดับกึ่งทางการ?
ก. การกล่าวเปิดงานประชุมระดับชาติ ข. การเขียนอภิปรายในห้องเรียน
ค. การคุยกับเพื่อนสนิททางโทรศัพท์ ง. การตรากฎหมายในรัฐสภา
9. ข้อใดใช้ภาษาต่างระดับจากข้ออื่น?
ก. นายกรัฐมนตรีเดินทางไปปฏิบัติราชการต่างประเทศ ข. กระทรวงสาธารณสุขแถลงข่าวเรื่องโรคระบาด
ค. ผอ. เรียกประชุมครูทุกคนเย็นนี้ ง. คณะกรรมการลงมติเห็นชอบร่างพระราชบัญญัติ
10. "ท่านประธานที่เคารพ กระผมขอเสนอความคิดเห็นเพิ่มเติมครับ" เป็นภาษาระดับใด?
ก. พิธีการ ข. ทางการ
ค. กันเอง ง. สนทนา
11. ข้อใดมีคำสแลงหรือคำภาษาปากที่ทำให้เป็นภาษาระดับสนทนา/กันเอง?
ก. ข้อสอบชุดนี้ปังมาก ทำเอาทุกคนงงไปตามๆ กัน ข. นักเรียนควรเตรียมตัวสอบอย่างสม่ำเสมอ
ค. การวิเคราะห์ข้อมูลต้องทำอย่างระมัดระวัง ง. การออมเงินเป็นสิ่งสำคัญสำหรับอนาคต
12. ภาษาที่ใช้ในการเขียนบทความวิชาการควรเป็นระดับใด?
ก. ทางการ ข. กึ่งทางการ
ค. สนทนา ง. พิธีการ
13. ข้อใด ไม่ถูกต้อง เกี่ยวกับภาษาระดับพิธีการ?
ก. มักใช้ในงานพระราชพิธี ข. ใช้คำสรรพนามที่แสดงความเคารพสูงสุด
ค. ใช้คำแสลงเพื่อสร้างความเป็นกันเอง ง. มีโครงสร้างประโยคที่สมบูรณ์และไพเราะ
14. "คุณหมอคนนี้รักษาเก่งจังเลยนะ" จัดอยู่ในภาษาระดับใด?
ก. ทางการ ข. กึ่งทางการ
ค. สนทนา ง. พิธีการ
15. ข้อใดเปลี่ยนภาษาระดับสนทนาว่า "หมอจับฉีดยา" ให้เป็นภาษาระดับทางการได้ถูกต้องที่สุด?
ก. แพทย์ทำการฉีดยา ข. คุณหมอฉีดยาให้
ค. ท่านหมอให้ยาฉีด ง. แพทย์จัดยาฉีด

ส่วนที่ 2: ชนิดของคำ (ข้อ 16 - 30)

16. "ความดี" และ "การเรียน" จัดเป็นคำนามชนิดใด?
ก. สามานยนาม ข. วิสามานยนาม
ค. อาการนาม ง. ลักษณะนาม
17. ข้อใดมีคำ "วิสามานยนาม"?
ก. สัตว์เลี้ยงมีหลายชนิด ข. เด็กๆ ชอบกินขนม
ค. โรงเรียนสวนกุหลาบวิทยาลัยตั้งอยู่ใกล้แม่น้ำเจ้าพระยา ง. ต้นไม้ให้ร่มเงาแก่มนุษย์
18. คำที่ขีดเส้นใต้ในประโยค "ใคร จะไปเที่ยวบ้าง" เป็นคำสรรพนามชนิดใด?
ก. ปฤจฉาสรรพนาม ข. อนิยมาสรรพนาม
ค. นิยมาสรรพนาม ง. วิภาคสรรพนาม
19. ประโยคใดมีคำ "วิภาคสรรพนาม"?
ก. ต่างคนต่างทำงานของตนเอง ข. นี่คือหนังสือที่ฉันชอบ
ค. ใครๆ ก็อยากมีความสุข ง. เขาเป็นคนดีมาก
20. "น้องหัวเราะเสียงดัง" คำว่า "หัวเราะ" เป็นคำกริยาชนิดใด?
ก. สกริยากริยา ข. อกริยากริยา
ค. วิกตรรถกริยา ง. กริยานุเคราะห์
21. "เขา เป็น นักบิน" คำว่า "เป็น" จัดเป็นกริยาชนิดใด?
ก. สกริยากริยา ข. อกริยากริยา
ค. วิกตรรถกริยา ง. กริยาสภาวมาลา
22. "ดอกไม้ดอกนี้มีกลิ่นหอม มาก" คำว่า "มาก" ทำหน้าที่เป็นคำชนิดใด?
ก. คำนาม ข. คำกริยา
ค. คำวิเศษณ์ ง. คำบุพบท
23. ข้อใดมีคำวิเศษณ์ขยายคำกริยา?
ก. เขาเดิน เร็ว มาก ข. บ้าน ใหญ่ หลังนั้นสวยงาม
ค. เสื้อ สีแดง ตัวนี้ราคาแพง ง. คน ขยัน ย่อมประสบความสำเร็จ
24. ประโยคใดใช้คำบุพบทได้ถูกต้อง?
ก. เขาถวายเงิน แก่ พระสงฆ์ ข. ครูมอบรางวัล แก่ นักเรียน
ค. เขายื่นหนังสือ ต่อ ศาล ง. ถูกทุกข้อ
25. คำว่า "บน" ในประโยค "หนังสือวางอยู่ บน โต๊ะ" เป็นคำชนิดใด?
ก. คำบุพบท ข. คำสันธาน
ค. คำวิเศษณ์ ง. คำอุทาน
26. "เขาอ่านหนังสือหนัก เพราะ ต้องการสอบผ่าน" คำว่า "เพราะ" เป็นคำชนิดใด?
ก. คำบุพบท ข. คำสันธาน
ค. คำอุทาน ง. คำวิเศษณ์
27. ข้อใดมีคำสันธานที่เชื่อมประโยคแบบ ขัดแย้งกัน?
ก. ถึงเขาจะยากจนแต่เขาก็มีความสุข ข. เพราะเขาอ่านหนังสือเขาจึงสอบผ่าน
ค. เธอจะกินข้าวหรือกินก๋วยเตี๋ยว ง. พอฝนตกเขาก็กลับบ้าน
28. "อุ๊ย! ตกใจหมดเลย" คำว่า "อุ๊ย!" เป็นคำชนิดใด?
ก. คำวิเศษณ์ ข. คำอุทานบอกอาการ
ค. คำอุทานเสริมบท ง. คำบุพบท
29. คำอุทานในข้อใดเป็นการ เสริมบท?
ก. อนิจจา! น่าสงสารเหลือเกิน ข. หนังสือหนังหาไม่ได้อ่านเลย
ค. ว้าย! ช่วยด้วย ง. ไชโย! เราชนะแล้ว
30. ข้อใดระบุชนิดของคำที่ขีดเส้นใต้ ไม่ถูกต้อง?
ก. ฝูง นกบินร่อนลม (ลักษณนาม) ข. เขา กำลัง ทำงาน (กริยานุเคราะห์)
ค. ท่าน จะไปไหนครับ (บุรุษสรรพนาม) ง. เขาเป็นคน ดี (คำวิเศษณ์)

ส่วนที่ 3: สำนวนไทย (ข้อ 31 - 40)

31. สำนวน "จับปลาสองมือ" หมายถึงอะไร?
ก. การทำงานพร้อมกันหลายอย่างจนไม่สำเร็จสักอย่าง ข. ความขยันขันแข็งในการทำงาน
ค. การมีความสามารถรอบด้าน ง. การฉวยโอกาสเมื่อมีช่องทาง
32. สำนวนใดมีความหมายตรงกับ "ทำความดีแต่ไม่มีใครเห็น"?
ก. ขี่ช้างจับตักแตน ข. ปิดทองหลังพระ
ค. ตำน้ำพริกละลายแม่น้ำ ง. น้ำเชี่ยวอย่าขวางเรือ
33. "เขายอมเสียสละทรัพย์สินส่วนตนเพื่อรักษาเกียรติยศไว้" ตรงกับสำนวนใด?
ก. เสียชีพอย่าเสียสัตย์ ข. สละเรือนหุ้น
ค. เสียสลึงเสียมิได้ ง. สละอวัยวะเพื่อรักษาชีวิต
34. สำนวน "กิ้งก่าได้ทอง" มีความหมายเปรียบเทียบถึงคนประเภทใด?
ก. คนที่เย่อหยิ่งเย่อหยิ่งเมื่อได้ดี ข. คนที่มีความรู้สูง
ค. คนที่ซื่อสัตย์สุจริต ง. คนที่ปรับตัวเก่ง
35. ข้อใดใช้สำนวน ไม่ถูกต้อง ตามบริบท?
ก. เขาทำตัวเป็น ขวานผ่าซาก พูดจาตรงไปตรงมาจนคนอื่นเสียน้ำใจ ข. งานนี้ง่ายเหมือน กล้วยเข้าปาก ใครๆ ก็ทำได้
ค. เธอเป็นคน ใจยักษ์ใจมาร ชอบช่วยเหลือผู้ยากไร้เสมอ ง. อย่าทำตัวเป็น วัวลืมตีน เมื่อได้ดีแล้วควรกตัญญู
36. สำนวน "สีซอให้ควายฟัง" มีความหมายใกล้เคียงกับข้อใดมากที่สุด?
ก. ตักน้ำรดหัวตอ ข. เข้าหูซ้ายทะลุหูขวา
ค. ไก่เห็นเท้างู งูเห็นนมไก่ ง. ข้อ ก และ ข ถูก
37. "ชี้โพรงให้กระรอก" หมายความว่าอย่างไร?
ก. การบอกแนวทางให้คนทำผิดหรือทำสิ่งที่ไม่ควรทำ ข. การช่วยเหลือคนยากไร้
ค. การสอนหนังสือให้เด็ก ง. การเตือนภัยล่วงหน้า
38. สำนวนใดหมายถึง "การทำอะไรเกินตัวจนได้รับความเดือดร้อน"?
ก. กบเลือกนาย ข. ความรู้ท่วมหัวเอาตัวไม่รอด
ค. คางคกขึ้นกอ ง. ขี่ช้างจับตักแตน
39. สำนวน "น้ำซึมซับทราย" หมายถึงอะไร?
ก. รายได้ที่เข้ามาเรื่อยๆ ไม่ขาดสาย ข. ความอดทนพยายาม
ค. ความสูญเสียที่ไม่ได้รับอะไรกลับคืน ง. ความสัมพันธ์ที่ยั่งยืน
40. "เอาหูไปนา เอาตาไปไร่" มีความหมายตรงกับข้อใด?
ก. ทำเป็นไม่รู้ไม่เห็น ไม่สนใจ ข. ขยันทำมาหากิน
ค. มีความระมัดระวังตัวตลอดเวลา ง. ชอบเที่ยวร่อนไปทั่ว

ส่วนที่ 4: เสียงในภาษาและโครงสร้างคำ (ข้อ 41 - 60)

วิเคราะห์เฉลยตามโครงสร้างตรรกะ: Process → Formula → Result

ข้อ เฉลย บทวิเคราะห์เชิงตรรกะ (Process → Formula → Result)
1ขพิจารณาคำราชาศัพท์ พิธีการ → พระราชพิธี/วโรกาส
2กพิจารณาทางการ ทางการ → หนังสือราชการ/ภาษาข่าว
3คมีภาษาพูดปะปนเล็กน้อย กึ่งทางการ → หมอ+เรียบเรียงเป็นทางการ
4ขคำว่า "นิดนึง" เป็นภาษาพูด สนทนา → ภาษาปาก
5กคำสรรพนาม "แก" กันเอง → ภาษาพูดสนิทสนม
6ขหนังสือราชการต้องถูกต้องตามระเบียบสารบรรณ → ทางการ
7ขมีการใช้คำราชาศัพท์ชั้นสูง → พิธีการ
8ขการอภิปรายใช้ภาษาเข้าใจง่ายแต่สุภาพ → กึ่งทางการ
9คคำว่า "ผอ." เป็นคำย่อภาษาปาก ต่างจากข้ออื่นที่เป็นภาษาระดับทางการ
10ขเป็นการพูดในที่ประชุมสภา → ทางการ
11กคำว่า "ปังมาก" เป็นคำสแลง → ภาษาปาก/สนทนา
12กงานวิชาการต้องการความถูกต้องเชิงอ้างอิง → ทางการ
13คภาษาระดับพิธีการห้ามใช้คำสแลงเด็ดขาด
14คคำว่า "จังเลยนะ" แสดงความเป็นกันเอง/สนทนา
15กแปลงคำว่า "หมอ → แพทย์" และ "จับฉีดยา → ทำการฉีดยา"
16คขึ้นต้นด้วย "ความ" และ "การ" + คำกริยา/วิเศษณ์ → อาการนาม
17คเจาะจงชื่อสถานที่ → วิสามานยนาม
18กคำว่า "ใคร" ต้องการคำตอบ → ปฤจฉาสรรพนาม
19กคำว่า "ต่าง" เป็นการจำแนก → วิภาคสรรพนาม
20ข"หัวเราะ" ความหมายสมบูรณ์ในตัวเอง ไม่ต้องมีกรรม → อกริยา
21ค"เป็น" ต้องมีส่วนเติมเต็ม → วิกตรรถกริยา
22ค"มาก" ขยายคำว่า "หอม" (คำวิเศษณ์) → คำวิเศษณ์
23ก"เร็ว" ขยายกริยา "เดิน" → วิเศษณ์ขยายกริยา
24งคำบุพบท "แก่" (ผู้รับ), "ต่อ" (ยื่นเสนอ) ถูกต้องทุกข้อ
25ก"บน" บอกตำแหน่งสัมพันธ์กับสถานที่ → คำบุพบท
26ข"เพราะ" เชื่อมเหตุและผล → คำสันธาน
27ก"ถึง...แต่..." เชื่อมความขัดแย้ง → คำสันธานขัดแย้ง
28ข"อุ๊ย!" แสดงอารมณ์ตกใจ → คำอุทานบอกอาการ
29ข"หนังสือหนังหา" คำหลังซ้ำเสริมเสียง → คำอุทานเสริมบท
30ก"ฝูง" วางไว้หน้าคำนามเพื่อบอกกลุ่ม ทำหน้าที่เป็น **หมวดนาม (ลักษณะนามบอกหมวดหมู่)** ไม่ใช่ลักษณะนามธรรมดา
31กเปรียบเทียบจับปลาสองมือ → เสี่ยงทำสองงานพร้อมกัน
32ขปิดทองด้านหลังองค์พระ → ทำดีไม่มีใครเห็น
33งตัดอวัยวะเพื่อรักษาชีวิต → สละสิ่งส่วนน้อยเพื่อรักษาหลักใหญ่
34กกิ้งก่าเมื่อได้ทองจะเหยียดตัวสูง → คนได้ดีแล้วเหยียดหยามคนอื่น
35ค"ใจยักษ์ใจมาร" แปลว่าใจร้าย แต่บริบทบอกชอบช่วยเหลือ จึงขัดแย้งกัน
36งสั่งสอนคนปัญญาอ่อนแอหรือไม่สนใจ → ตักน้ำรดหัวตอ / เข้าหูซ้ายทะลุหูขวา
37กชี้ช่องทางให้กระรอก → บอกช่องทางทำผิด
38งขี่ช้างจับตักแตน → ลงทุนมากแต่ได้ผลน้อย/ทำเกินตัว
39กซึมทีละนิดเรื่อยๆ → รายได้หรือประโยชน์ที่เข้ามาเรื่อยๆ
40กไม่เอาหูเอาตาไปรับรู้ → ทำเป็นไม่รู้ไม่เห็น
41คพ่อ + แม่ (คำที่มีความหมายตรงข้ามหรือคล้ายกันมารวมกัน) → คำซ้อนเพื่อความหมาย
42กคำแยกส่วนแล้วไม่มีความหมายดั้งเดิม (กะ+ทิ, นา+ฬิ+กา) → คำมูล
43กแม่+น้ำ = สายน้ำใหญ่, พ่อ+ตา = พ่อของเมีย, ใจ+แคบ = ไม่ใจกว้าง → คำประสมทุกคำ
44ขนำคำความหมายใกล้เคียงมารวมกัน → คำซ้อนเพื่อความหมาย
45กซ้อนสัมผัสพยัญชนะ/สระเพื่อความไพเราะ → คำซ้อนเพื่อเสียง
46ขใช้คำซ้ำเปลี่ยนความหมายเป็น "ง่าย" → คำซ้ำ
47กเสียงแม่กบ = บ, ป, พ, ฟ, ภ
48งถ, ฎ, ธ, ศ, ษ, ต จัดอยู่ในแม่กดทั้งหมด
49กรูป (แม่กบ) - ภาพ (แม่กบ) → กบ-กบ

51คคำว่า "พ่อ" (อักษรต่ำ) รูปเอก → เสียงโท
52กพยัญชนะ 44 รูป แต่มีเสียงแปรเพียง 21 เสียง
53กสระเดี่ยว (สระแท้) มี 18 เสียง (สั้น 9, ยาว 9)
54กสระประสมได้แก่ เอียะ-เอีย, เอือะ-เอือ, อัวะ-อัว (เสือ=เอือ, เมือง=เอือ, เสีย=เอีย)
