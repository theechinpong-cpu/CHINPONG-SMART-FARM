📐 ข้อสอบปลายภาคเรียนที่ 1 คณิตศาสตร์ ม.2 (ระดับเข้มข้น สสวท.)

📘 สรุปสาระสำคัญและกระบวนการคิดวิชาคณิตศาสตร์ ม.2 ภาคเรียนที่ 1

1. ทฤษฎีบทพีทาโกรัส: c² = a² + b² ด้านตรงข้ามมุมฉากยาวที่สุดเสมอ จำชุดอัตราส่วนยอดฮิต: 3-4-5, 5-12-13, 7-24-25, 8-15-17 และ 9-40-41 บทกลับใช้เช็กชนิดสามเหลี่ยม: c² > a² + b² เป็นมุมป้าน, c² < a² + b² เป็นมุมแหลม

2. ความรู้เบื้องต้นเรื่องจำนวนจริง: จำนวนจริงประกอบด้วยจำนวนตรรกยะ (เศษส่วน ทศนิยมซ้ำ รู้จบ) และอตรรกยะ (ทศนิยมไม่รู้จบไม่ซ้ำ รากถอดไม่ลงตัว ค่า π) รากที่สองของ a² คือ |a|

3. ปริซึมและทรงกระบอก: ปริมาตร = พื้นที่ฐาน × สูง | พื้นที่ผิวข้างทรงกระบอก = 2πrh | พื้นที่ผิวทั้งหมดทรงกระบอก = 2πr(h + r)

4. การแปลงทางเรขาคณิต: การเลื่อนขนาน (พิกัดขยับคงที่ตามเวกเตอร์), การสะท้อน (ระยะห่างจากเส้นสะท้อนเท่ากัน), การหมุน (มุมและทิศทางรอบจุดศูนย์กลางการหมุน)

5. พหุนาม: การบวก-ลบเอกนามที่คล้ายกัน, การคูณพหุนามด้วยการแจกแจงทุกพจน์ และการหารพหุนาม

💡 กล่องเทคนิคการจำและวิธีคิดลัด (Tutor Memory Tricks)
• พีทาโกรัสใน 3 มิติ: เส้นทแยงมุมกล่องสี่เหลี่ยม = √(กว้าง² + ยาว² + สูง²)
• ถอดรากที่สอง: √(x²) = |x| เสมอ (ผลลัพธ์ห้ามติดลบ)
• หมุนพิกัด 90° ทวนเข็ม: (x, y) ➔ (-y, x) | หมุน 180°: (x, y) ➔ (-x, -y)
• ทรงกระบอก: พื้นที่ผิวทั้งหมด = 2πr(h + r) ช่วยลดขั้นตอนการคำนวณซ้ำซ้อน
