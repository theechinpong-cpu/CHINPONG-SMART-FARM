แบบทดสอบวัดผลสัมฤทธิ์วิชาภาษาไทย ม.1

โดย พระจอมเกล้าติวเตอร์ (ข้อสอบมาตรฐานเชิงวิเคราะห์ 20 ข้อ)
1. ข้อใดมีจำนวน "คำตาย" มากที่สุด?
เฉลย: D (คำตอบที่ถูกต้อง)
คำอธิบาย: คำตายคือคำที่สะกดด้วยมาตรา กบ, กก, กด หรือสระเสียงสั้นแม่ ก กา
- ข้อ D มีคำตาย 6 คำ ได้แก่ สุ-, -นัข (กก), จอก (กก), กัด (กด), กระ- (สระสั้น), -ดูก (กก), แพะ (สระสั้น)
2. ข้อความใดประกอบด้วยคำที่มีเสียงพยัญชนะต้นเป็น "อักษรควบแท้" ทั้งหมด?
เฉลย: A
คำอธิบาย: อักษรควบแท้ต้องออกเสียงพยัญชนะต้น 2 ตัวพร้อมกัน (ปล-, ปร-, พล-, ขว-) ส่วนข้อ B และคำว่า ปราศรัย (ศร ออกเสียง ศ), สระน้ำ (สร ออกเสียง ส), จริง (จร ออกเสียง จ) เป็นอักษรควบไม่แท้
3. ข้อใดเป็น "คำประสม" ทุกคำ?
เฉลย: A
คำอธิบาย: แม่ทัพ, รถไฟ, ทางผ่าน เกิดจากคำมูลรวมกันเกิดความหมายใหม่ทุกคำ ส่วน 'บ้านเรือน' เป็นคำซ้อนเพื่อความหมาย, 'ร้องไห้' เป็นคำซ้อน, 'ผ้าขาวม้า' เป็นคำยืมภาษาเปอร์เซีย
4. คำในข้อใดเป็น "คำสมาสที่ไม่มีการสนธิ" ทุกคำ?
เฉลย: A
คำอธิบาย: วัฒน+ธรรม, ภูมิ+ศาสตร์, ราช+การ เป็นคำบาลี-สันสกฤตชนกันโดยตรง ข้อ B มีสนธิ (เทพ+อารักษ์, คมน+อาคม), ข้อ C มีคำไทยปน (ผลไม้ ไม่ใช่สมาส), ข้อ D มีสนธิ (มหา+อวิทยาลย)
5. คำซ้อนในข้อใดมีลักษณะเป็น "คำซ้อนเพื่อเสียง" ทั้งหมด?
เฉลย: C
คำอธิบาย: ป้ำเป๋อ, โซเซ, ตูมตาม เกิดจากการนำคำที่มีเสียงสระหรือพยัญชนะคล้องจองมาซ้อนกันเพื่อเน้นเสียง ไม่ได้นำคำที่มีความหมายเหมือนหรือตรงข้ามมาประกบกันตรงๆ
6. คำว่า "ที่" ในข้อใดทำหน้าที่เป็น "ประพันธสรรพนาม" (เชื่อมประโยคและแทนนามข้างหน้า)?
เฉลย: B
คำอธิบาย: คำว่า "ที่" ในข้อ B ทำหน้าที่เป็นประพันธสรรพนาม แทนคำว่า "นักเรียน" และเชื่อมอนุประโยค "ชนะการประกวด" เข้ากับประโยคหลัก ส่วนข้อ A เป็นคำนาม (ที่ดิน), ข้อ C เป็นบุพบท (อยู่ที่)
7. "คนโบราณเชื่อว่าจิ้งจกทักเป็นลางบอกเหตุ" คำที่ขีดเส้นใต้ (ว่า) จัดเป็นคำชนิดใด?
เฉลย: A
คำอธิบาย: "ว่า" ทำหน้าที่เชื่อมประโยคย่อยที่เป็นบทกรรม (นามานุประโยค) เข้ากับประโยคหลัก จึงเป็นคำสันธานเชื่อมประโยคความซ้อน (สังกรประโยค)
8. ข้อใดเป็น "ประโยคความเดียว" (เอกรรถประโยค)?
เฉลย: A
คำอธิบาย: ข้อ A มีประธานเดียว (นกพิราบ) และกริยาหลักเดียว (ร้องเพลง) พร้อมส่วนขยาย ไม่มีประโยคอื่นมาซ้อนหรือรวม ส่วน B เป็นความรวม, C เป็นความซ้อน (ลูกที่มี...), D เป็นความรวมขัดแย้ง
9. ประโยคในข้อใดเป็น "ประโยคความซ้อน" (สังกรประโยค)?
เฉลย: C
คำอธิบาย: สังเกตประพันธสรรพนาม "ซึ่ง" เชื่อมประโยคย่อย (ปฏิบัติตนตามระเบียบ) ขยายประธาน (บุคคล) จึงเป็นประโยคความซ้อนประเภทยคุณานุประโยค
10. ข้อใดใช้คำราชาศัพท์ได้ถูกต้องตามหลักไวยากรณ์?
เฉลย: D
คำอธิบาย: ทรง + มี + พระราช... ใช้ถูกต้องเมื่อมีคำว่า "พระราช" นำหน้านาม ส่วนข้อ A และ B ห้ามใช้ "ทรงเสด็จ" (เสด็จ เป็นราชาศัพท์แท้อยู่แล้ว) และข้อ C ห้ามใช้ "ทรงโปรด" ต้องใช้ "โปรดเกล้าฯ" หรือ "ทรงพระกรุณาโปรดเกล้าฯ"
11. พระสงฆ์ "จำวัด" และ "มรณภาพ" มีความหมายตรงกับข้อใดตามลำดับ?
เฉลย: B
คำอธิบาย: คำศัพท์สำหรับพระสงฆ์: จำวัด = นอนหลับ, มรณภาพ = ถึงแก่กรรม (ตาย), อาพาธ = ป่วย, ฉัน = รับประทาน
12. "เขารับทำงานหลายอย่างพร้อมกันจนผลงานออกมาไม่มีคุณภาพสักชิ้น" ตรงกับสำนวนใด?
เฉลย: B
คำอธิบาย: "จับปลาสองมือ" หมายถึง หมายจะได้ทั้งสองอย่างพร้อมกันจนสุดท้ายไม่ได้ผลดีสักอย่าง ส่วน "เหยียบเรือสองแคม" หมายถึง ทำทีเข้าด้วยทั้งสองฝ่ายที่ไม่ถูกกันเพื่อประโยชน์ตน
13. สำนวนในข้อใดมีความหมาย "ตรงข้าม" กับสำนวน "ถี่ลอดตาช้าง ห่างลอดตาเล็น"?
เฉลย: C
คำอธิบาย: "ถี่ลอดตาช้าง ห่างลอดตาเล็น" มีความหมายเดียวกับ "เสียน้อยเสียยาก เสียมากเสียง่าย" คือ ดูเหมือนรอบคอบในเรื่องเล็กแต่อนุโลมให้เรื่องใหญ่เสียหาย ดังนั้นความหมายตรงข้ามคือ "ละเอียดลออ รอบคอบรัดกุม"
14. ข้อใดเขียนสะกดคำได้ "ถูกต้องทุกคำ"?
เฉลย: A
คำอธิบาย: - กะเพรา (ไม่มี ร ที่ กะ)
- อนุญาต (ไม่มี สระอิ ที่ ต)
- สังเกต (ไม่มี สระอุ ที่ ต)
- ปรากฏ (ใช้ ฏ ปฏัก ไม่ใช่ ฎ ชดา)
15. คำในข้อใดมีตัวการันต์ที่ "ไม่ออกเสียงพยัญชนะ 2 ตัว"?
เฉลย: C
คำอธิบาย: พระจันทร์ ไม่ออกเสียง "ทร" (มีไม้ทัณฑฆาตกำกับบน ร ทำให้ไม่ออกเสียง ท และ ร รวม 2 ตัว) ส่วน ประดิษฐ์ ฆาตเฉพาะ ฐ, กษัตริย์ ฆาตเฉพาะ ย, สัมพันธ์ ฆาตเฉพาะ ธ
16. ข้อความใดใช้ภาษาใน "ระดับทางการ"?
เฉลย: B
คำอธิบาย: ข้อ B ใช้ภาษาแบบแผน ไวยากรณ์ถูกต้อง ไม่มีคำสแลงหรือคำปาก ส่วนข้ออื่นมีคำระดับปาก (หมอ -> แพทย์, พลาดโอกาสทอง, พวกแก๊ง)
17. กลอนสุภาพบทหนึ่ง วรรคสดับลงท้ายด้วยเสียง "จัตวา" วรรครับควรลงท้ายด้วยเสียงวรรณยุกต์ใดจึงจะไพเราะและถูกต้องตามแบบแผนที่สุด?
เฉลย: B
คำอธิบาย: ตามฉันทลักษณ์กลอนสุภาพ คำสุดท้ายของ "วรรครับ" นิยมใช้เสียง **จัตวา** มากที่สุด และอนุญาตให้ใช้เสียง **เอก** หรือ **โท** ได้ แต่ **ห้ามลงด้วยเสียงสามัญและตรี**
18. ข้อใดใช้ภาพพจน์ประเภท "อุปมา" (การเปรียบเทียบว่าเหมือน)?
เฉลย: B
คำอธิบาย: ข้อ B มีคำเชื่อมแสดงการเปรียบเทียบคือคำว่า "ดั่ง" (อุปมา) ส่วนข้อ A และ C ใช้ "คือ/เป็น" จัดเป็น "อุปลักษณ์" และข้อ D นำคุณลักษณะมนุษย์ไปใส่ในสิ่งไม่มีชีวิต จัดเป็น "บุคคลวัต"
19. "อันอ้อยตาลหวานลิ้นแล้วสิ้นซาก แต่ลมปากหวานหูไม่รู้หาย" ผู้แต่งมุ่งเน้นสั่งสอนในเรื่องใด?
เฉลย: B
คำอธิบาย: บทกลอนของสุนทรภู่ต้องการชี้ให้เห็นว่า ความหวานของอาหารสัมผัสประเดี๋ยวเดียวก็หมดไป แต่คำพูดจาที่ไพเราะ อ่อนหวาน จะตราตรึงอยู่ในใจของผู้ฟังยาวนาน
20. ข้อความใดมีเจตนา "ประชดประชัน"?
เฉลย: B
คำอธิบาย: "ผิวดวงจันทร์" มีลักษณะเป็นหลุมเป็นบ่อ การกล่าวว่า "ถนนเรียบเนียนราวกับผิวดวงจันทร์" จึงเป็นการใช้คำชมเพื่อเสียดสีและประชดประชันสภาพถนนที่เป็นหลุมบ่อ
