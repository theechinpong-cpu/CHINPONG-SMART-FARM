🏆 ข้อสอบคณิตศาสตร์ ป.6 ปลายภาคเรียนที่ 1 (ระดับเข้มข้น ห้อง Gifted / สอบแข่งขัน)

📘 สรุปหัวใจสำคัญคณิตศาสตร์ ป.6 เทอม 1 สู่ห้องเรียนพิเศษ

1. ห.ร.ม. และ ค.ร.น.: ห.ร.ม. คือ "ตัวหารร่วมที่มากที่สุด" เน้นการตัดแบ่งสิ่งของให้เท่ากันโดยไม่เหลือเศษ ส่วน ค.ร.น. คือ "ตัวคูณร่วมที่น้อยที่สุด" เน้นเหตุการณ์ที่เกิดขึ้นพร้อมกันในอนาคต จำสูตรเด็ด A × B = ห.ร.ม. × ค.ร.น. เสมอ

2. เศษส่วนและทศนิยมระคน: คำนวณตามลำดับศักดิ์เครื่องหมาย: วงเล็บ ➔ คูณ/หาร (จากซ้ายไปขวา) ➔ บวก/ลบ (จากซ้ายไปขวา) ห้ามคำนวณเรียงจากซ้ายไปขวาโดยไม่สนลำดับเด็ดขาด

3. อัตราส่วนและร้อยละ: การเปรียบเทียบปริมาณหลายจำนวนให้หาอัตราส่วนเชื่อมโยง (ตัวเชื่อม) เพื่อรวมเป็นอัตราส่วนต่อเนื่อง โจทย์กำไร-ขาดทุนให้ระลึกเสมอว่าต้องเทียบกับ "ราคาทุน" เป็นฐาน 100%

4. แบบรูป: พิจารณาผลต่างระหว่างพจน์ หากผลต่างคงที่เท่ากับ d พจน์ที่ n จะอยู่ในรูป dn + c

💡 กล่องเทคนิคการจำและวิธีคิดลัด (Tutor Memory Tricks)
• ห.ร.ม. เหลือเศษ: "นำเศษไปลบออกจากตัวตั้งก่อน แล้วค่อยหา ห.ร.ม."
• ค.ร.น. เหลือเศษ: "หา ค.ร.น. ให้เสร็จก่อน แล้วค่อยบวกเศษเพิ่มเข้าไป"
• อัตราส่วนเชื่อม: ทำให้ตัวร่วมเท่ากันด้วย ค.ร.น. เช่น A:B = 2:3 และ B:C = 4:5 ➔ ทำให้ B เป็น 12 ได้ 8:12:15
• ลำดับการคำนวณ: "วงเล็บ ➔ คูณ/หาร ➔ บวก/ลบ"
