สรุปหลักไวยากรณ์ภาษาจีน: คำศัพท์อวัยวะบนใบหน้า การใช้ 的 (de) 很 (hěn) และโครงสร้างขยายคำนาม-กริยา

ชุดข้อสอบภาษาจีนชุดนี้ (จำนวน 35 ข้อ) สร้างขึ้นจากรายการคำศัพท์และประโยคต้นแบบในสมุดจดของนักเรียนทั้ง 2 หน้าอย่างครบถ้วน พร้อมแสดง พินอิน (Pinyin) ควบคู่บนตัวอักษรจีนทุกประโยค และรองรับ Popup แสดงคำอ่าน พินอิน ชนิดของคำ และคำแปลภาษาไทยทันทีเมื่อนำเมาส์ไปชี้ที่คำศัพท์ภาษาจีนทุกคำ เพื่อให้นักเรียนฝึกแต่งประโยคและแยกแยะหน้าที่ของ คำขยายคำนาม (定语 dìngyǔ) กับ คำกริยา / ภาคแสดง (谓语 wèiyǔ) ได้อย่างเข้าใจลึกซึ้งและจดจำได้รวดเร็ว

1. คลังคำศัพท์จากสมุดทั้ง 2 หน้า (12 คำหลัก + ประโยคต้นแบบ 我的眼睛很大)

2. ความแตกต่างระหว่าง "คำขยายคำนาม" กับ "คำกริยา / ภาคแสดง" ในภาษาจีน

หัวใจสำคัญที่นักเรียนไทยมักทำผิดคือการสลับตำแหน่งคำขยายกับคำนาม ในภาษาไทยเราพูดว่า "ผมยาว" หรือ "ตาโต" (คำนามอยู่หน้า คำขยายอยู่หลัง) แต่ในภาษาจีนมี 2 โครงสร้างที่ต่างกันชัดเจน:
• โครงสร้างวลีนาม (คำขยายคำนาม + 的 + คำนาม): คำขยายต้องวางไว้ ข้างหน้าคำนามเสมอ เช่น 长长的头发 (ผมที่ยาว), 大大的眼睛 (ดวงตาที่โต), 我的鼻子 (จมูกของฉัน) ในที่นี้คำว่า 长, 大, 我 ทำหน้าที่เป็น คำขยายคำนาม
• โครงสร้างประโยคภาคแสดง (ประธาน + 很 + คำคุณศัพท์): เมื่อต้องการบรรยายลักษณะเป็นประโยคสมบูรณ์ (เช่น ประโยคต้นแบบในสมุด 我的眼睛很大) คำว่า 大 (ใหญ่/โต), 长 (ยาว), 高 (สูง/โด่ง), 小 (เล็ก) จะทำหน้าที่เป็น คำกริยาคุณศัพท์ (ภาคแสดงหลักของประโยค) โดยมีคำวิเศษณ์ 很 วางขยายไว้ข้างหน้า และ ห้ามใช้ 是 (shì) คั่นกลางเด็ดขาด

3. การใช้คำกริยาแท้ร่วมกับคำศัพท์ในชุด (เช่น 有 yǒu = มี, 留 liú = ไว้ผม, 看 kàn = ดู)

เมื่อนำวลีนามที่มีคำขยายไปใส่ในประโยคที่มีคำกริยาแท้ เช่น 我有大大的眼睛。 (ฉันมีดวงตาที่โต) คำกริยาหลักของประโยคคือ 有 (มี) ส่วน 大大的 เป็นคำขยายคำนาม 眼睛 และหากต้องการขยายคำกริยาให้ทำอย่างละเอียดรอบคอบ สามารถใช้คำว่า 仔 ในรูปคำซ้อน 仔细地 (zǐxì de = อย่างละเอียด) วางหน้าคำกริยาได้

เทคนิคการจำและวิธีใช้งานฟีเจอร์ช่วยเรียน (สูตรครูตู่ พระจอมเกล้าติวเตอร์):
• วิธีดูคำแปล Popup: นำเมาส์ไปชี้ (หรือแตะบนหน้าจอมือถือ) ที่คำศัพท์ภาษาจีนคำใดก็ได้ที่มีเส้นประสีน้ำเงินด้านล่าง จะมีกล่อง Popup แสดง พินอิน + ชนิดของคำ + คำแปลภาษาไทย ทันที
• สูตรจำตำแหน่งคำขยายนาม: "ขยายอยู่หน้า นามอยู่หลัง มี 的 คั่นกลาง" → เช่น 我的 (ขยาย) + 眼睛 (นาม) = 我的眼睛 (ตาของฉัน)
• สูตรจำประโยคบรรยายลักษณะ: "ประธาน + 很 + คำคุณศัพท์ (กริยาภาคแสดง)" → เช่น 我的眼睛 + 很 + 大 (ห้ามใส่ 是 เด็ดขาด!)
• ระบบป้องกันการเดา: สลับลำดับตัวเลือก ก ข ค ง ด้วย Fisher-Yates Shuffle ทุกครั้งที่เริ่มใหม่ และล็อกคำตอบทันทีเมื่อคลิกเลือก
